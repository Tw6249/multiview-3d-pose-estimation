# 视觉四项改进：接口与复现（2026-10-18）

本轮针对遮挡/左右混淆、形状与姿态联合估计、完整人体状态、不确定性与在线延迟。算法候选必须通过配对评测才替换默认路径；新增代码不等于问题已解决。数值结论见 [验收报告](../reports/vision-joint-state-2026-10-18.json)。

| 独立模块 | 输入 → 输出 | 失败行为与验证 |
|---|---|---|
| `joint_window.JointWindow` | 原始多视角三角化、已关联 2D 像素、相机标定 → 五帧因果联合拟合的当前 3D 点与诊断 | 缺失不补成观测；拟合失败/修正过大返回原始点；骨长学习只用原始观测。常速度、时间连续性、原始形状证据和协方差不收缩回归 |
| `body_head_experiment` | 同一当前 RGB 人物框 → M/X 两种 COCO17 身体点 | 不改变人物选择、脚手细节或曝光时间；无框不推理、非有限值拒绝。相同框的新 M 输出必须复现缓存，X 只作为实验候选 |
| `kinematic_observability.KinematicObservability` | 当前滤波点及完整 3×3 位置协方差 → 躯干/足掌/手掌标志点坐标系、局部旋转协方差、角速度尺度、膝肘弯曲角 | 缺失、预测点、退化几何均未知；轴向扭转、骨盆/腰分解、地面反力不估计。坐标旋转等变性、噪声尺度、退化回归；保留独立诊断接口 |
| `landmark_velocity.LandmarkVelocity` | 原始多视角位置及质量 → 九帧二次拟合在当前曝光端点的速度与协方差 | 缺失/弱观测清空该点历史；不覆盖 Kalman 速度，不重复使用滤波后的点作为独立证据。解析加速运动与缺失回归；真实数据不通过则不启用 |
| `empirical_bounds` | 开发后独立校准时间段的参考误差/尺度 → 绑定估计器哈希与域的经验范围 | 相邻块并不独立，不声称分布无关保证；不写入控制门许可。域、哈希、缺失点、块数量及归一化尺度回归 |

全部长度 m、位置协方差 m²、速度 m/s、速度协方差 m²/s²；右手世界 Z 向上。旋转矩阵将局部坐标变换至世界，旋转扰动/角速度在世界系，单位 rad、rad/s。使用原始曝光整数 ns；错误/重复时间拒绝，换人/模型/标定或长间断清空历史。联合求解/低维诊断留 CPU，图像模型固定使用 CUDA。

联合窗口的重投影、加速度、软骨长残差同时求解；软骨长可调整，不把初始化固化成真值。仍只使用已解码单个 2D 峰、当前三角化内点及有限时域，无法恢复完全丢失的图像假设。缺少联合跨点/跨帧协方差，数值 Jacobian 只提供局部误差传播，不能自动称为概率校准。

## 评测隔离

- 长片 S1/S2 各前 500 帧为开发，后 250 帧仅作选择后的不确定性校准；S4/S6 各 750 帧在参数冻结后评测。代码、模型、检测和相机均记哈希，参考标注在各方法推理完成后才打开。S4/S6 在历史研究中已被查看，不能再称全新独立测试集。
- MPI-INF-3DHP 的 3D 参照来自无标记多视角采集；本轮 12 个身体关节近似对应，没有独立光学标记系统、足掌旋转、力或接触真值。位置不做刚体/尺度/时间对齐；缺失目标保留在成功率分母中。
- 同时报共同有效点误差、所有目标成功率、当前观测覆盖率、>500 mm 尾部、状态重获跳变和动作相位。状态重获不是有物理标注的遮挡事件，相位量化为 40 ms；不能用这些替代脚滑/接触准确率。
- 旋转/速度另用历史前端的 1,800 帧短片审计，不与新人物选择基线混算。差分参照速度含标注噪声；标志点旋转不是解剖学全关节旋转。
- `stream_vision.py --no-states` 保留紧凑时延统计。主机按时调度的文件回放含解码、实际 GPU/CPU 计算、队列丢弃；不是物理相机曝光时延。未校准 RGB 的控制门仍禁止 follow。
- 回放源在解码前按原曝光时间跳过过期帧，并预留最近解码耗时（最多起始年龄预算的一半），避免磁盘变慢后无限追赶旧帧；消费者继续检查真实年龄。统计窗口限 4,096 帧，`--no-states` 不在内存累计完整状态。压力测试保留所有目标/丢弃计数，不给旧帧重新打时间戳。
- 本机回放默认从 `vision_motion.json` 读取 4 路检测、4 路姿态推理；144 帧串并行结果逐值相同。直行实测约 8.8→11.3 Hz，尚未达到 24 Hz；每相机额外注入 10 ms 解码延迟后，积压被限制，但及时输出仍为零。10 Hz 回放放慢了源动作，不能称为 10 Hz 真实运动跟踪验收。

## 研究依据与差距

- [MEOM，2026-08](https://arxiv.org/abs/2608.30521)：保留热图多峰概率质量，并单独检查概率校准。本轮尚未实现热图层融合；继续在单峰坐标上增加平滑不足以解决对称歧义。
- [TEMPO，ICCV 2023](https://arxiv.org/abs/2309.07910)：学习共享空间/时间表示并复用人物特征。本轮是几何优化与现有检测器，未训练或复现该网络；延迟需全链路测量。
- [UPose3D，ECCV 2024](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/02418.pdf)：联合跨视角不确定性与时序骨架结构。本轮借鉴分离观测误差和结构约束的思路，不能称为论文复现。
- [RTMPose](https://arxiv.org/abs/2303.07399)：用官方 M/X 导出权重隔离二维前端容量的收益。更大模型不是最新最优方法，跨数据集、训练重叠和关节定义未统一时不能比较榜单数字。

复现入口：固定 `.robot-runtime.json` Python 运行 `benchmark_joint_vision.py`、`benchmark_kinematic_state.py`、`calibrate_visual_bounds.py`；固定 `.runtime.json` Python 运行 `benchmark_body_head.py`、`stream_vision.py`。所有评测要求新的输出目录，留出运行传入对应 `--expected-freeze`。大模型在用户 RTMLib 缓存，数值证据在忽略的 `outputs/vision_joint_round`；不复制 RGB 视频或完整状态轨迹。

历史冻结哈希对应实验当时的代码。留出前只修复了一处 JSON 元组/列表比较，记录于 `body_head_freeze_serialization_fix.json`；评分完成后增加模型校验、持久化校准分母下限及回放源/线程设置，未更改离线姿态求解参数。使用当前代码复现时应重新完成开发冻结，再运行留出，不能篡改旧清单使哈希通过。
