# 视觉姿态前沿调研与迁移决策（2026-10-18）

目标仍是无标记、多相机观察人，将同侧全身动作与源步态传给 G1 EDU。此次检索论文原文、作者项目与官方仓库；重点覆盖 2025–2026，最新纳入 2026-09 的工作。下表是作者报告，**不是我们的复现结果，也不是同一排行榜**。

## 值得借鉴的方法与实际证据

| 工作 / 状态 | 方法与论文效果 | 对我们有用的部分与限制 |
|---|---|---|
| [MEOM](https://arxiv.org/html/2608.30521v1)，2026-08-31 预印本 | 保留位置分布，以 Expected-OKS 聚合多视角。相同冻结网络下，H36MA 绝对 MPJPE：加权 DLT **41.28→37.72 mm（−8.6%）**；直接优化原始热图为 92.25 mm，反而失败 | 优先研究分布融合和 HDR 覆盖率校准。19.11 mm 来自另一套有三维监督训练的设置；158.2 对 301.4 GFLOPs 不等于整条链路时延减半。此次未核实到作者公开实现 |
| [ProbPose](https://openaccess.thecvf.com/content/CVPR2025/papers/Purkrabek_ProbPose_A_Probabilistic_Approach_to_2D_Human_Pose_Estimation_CVPR_2025_paper.pdf)，CVPR 2025；[BBoxMaskPose v2](https://arxiv.org/html/2601.15200v1)，2026-01 预印本 | 区分位置分布、点是否在窗口内、可见性；人物掩码与姿态迭代互相修正。BMPv1→v2+：OCHuman test AP **49.2→55.8（+6.6 个百分点）**；OCHuman-Pose **79.9→86.8** | 最值得优先试验的二维前端路线，针对错误人物与遮挡。额外分割/迭代有成本；小人物上可能退化。ProbPose 消融显示概率图本身未额外提高裁剪增强后的 AP，收益不能全部归因于概率表示 |
| [TwinPose](https://zgspose.github.io/TwinPose/)，SIGGRAPH / TOG 2026 | 将每个二维实例对应到几何一致的三维候选，以共享骨段关联，分人物子空间求解。作者报告 Shelf 求解约 **0.92 ms/帧** | 借鉴实例级候选与局部可靠骨段关联，不只逐点左右交换。该耗时不是 RGB 到状态输出延迟；此次没有统一其检测器、关节协议并复算精度收益 |
| [MAMMA v4](https://arxiv.org/abs/2506.13040v4)，2026-04 修订 / CVPR 2026 | 密集表面点、掩码、可见性、接触预测联合 SMPL-X 拟合。Hi4D 的 19 点 MPJPE：AvatarPose **32.10→MAMMA-C 12.44 mm**；MammaEval-D 的 55 点：CameraHMR **20.41→MAMMA 17.71 mm** | 用密集观测补体型、肢体旋转和脚手信息。v4 表 4/5 已逐页核对：使用**真值框、SAM2 掩码**，不能冒充完全自动检测成绩。接触优化主要减少穿透，未普遍改善 MPJPE；离线优化不是在线跟踪 |
| [SAM 3D Body](https://arxiv.org/html/2602.15989v1)，权重 2025-11 / 论文 2026-02 | MHR 分离骨架结构与表面形状；单图恢复身体、手脚。EMDB 的 24 点 MPJPE：CameraHMR **70.3→61.7 mm（−12.2%）**；表中 DINOv3 版本 | 适合作为体型/旋转候选或离线教师。单图先验输出不能自动成为多视角可观测真值；MHR、SMPL-X、COCO 的定义必须转换。840M 主干的四相机在线成本须实测 |
| [STA-TFM](https://arxiv.org/html/2609.24482v1)，2026-09-21 预印本 | 冻结 MotionBERT/DSTformer 提取每视角时序特征，学习跨视角融合、位置与速度损失。DHP19 相比 MPL：**P-MPJPE 35.78→17.56 mm**；P-MPJVE **3.29→1.66 mm/帧** | 借鉴学习式时序特征和视角缺失训练。指标经过平移、旋转、尺度 Procrustes 对齐，不能证明绝对位置/航向/体型正确。36 帧窗口的推理耗时不等于因果在线时延；SG 平滑基线速度指标 1.28 还更低，不能只摘有利比较 |
| [SONIC / GEAR-SONIC](https://github.com/NVlabs/GR00T-WholeBodyControl)，2025-11 论文、2026 持续发布 | 全身运动跟踪策略、编码器/解码器、训练和部署已公开。官方低延迟版需约 **80 ms** 未来参考，默认/v1.1 约 **200 ms**；控制频率 50 Hz | 优先考虑作为后续全身控制对照。我们的视觉输出没有真实未来帧，必须计入等待或预测误差；不能把控制频率当视觉采样率。使用完整腿部/骨盆参考，三点遥操作不足以满足本项目 |
| [PGMT](https://arxiv.org/html/2609.08511v1)，2026-09 预印本 | 运动跟踪后注入地形感知，并允许必要的下肢参考偏移。9,600 个配对 30 秒仿真回合，平地预训练→完整方法完成率 **40.02%→87.81%**；同样地形训练的 CNN 为 87.38% | 借鉴参考动作、实际支撑和地形共同决定可执行性。大幅收益包含地形训练，不能全部归功于注意力模块；不是我们的视觉误差改进。作者项目页未提供可核实的官方代码；同名第三方复现不算官方 |

MAMMA 此次以 v4 为准，不能沿用 v1 的 13.43 mm、真值轮廓或 8 小时运行数字。v4 的独立附加标记误差为 MAMMA 22.481 mm、Vicon+MoSh++ 21.619 mm；这是估计人体表面对留出标记的误差，**不是系统达到亚毫米精度**。标记只属于外部评测参照，实际感知仍必须无标记。

## 已落地的准备与效果边界

新增独立 `pose_sim/spatial_evidence.py`，在 RTMPose 解码前保留原始 X/Y 响应。输入为当前 BGR 图、人物框和模型；输出原解码结果及只读证据，包含相机、原曝光整数 ns、时钟域、模型 SHA、关节顺序和裁剪变换。坐标为输入图像像素（x 向右、y 向下），响应无量纲；缺失框、布局错误、非有限值拒绝，不复用历史。消费者仍负责标定绑定、同步和过期检查。

固定 CUDA 环境，在 S1/S2 开发片段各前 32 帧、共 **64 帧 / 256 裁剪**核验：关键点、分数及裁剪映射与缓存基线最大差异均 **0**。每四相机原始响应约 **238 KiB**，不保存逐帧分布。6 项相关回归通过，详见 [接口验收](../reports/frontier-research-2026-10-18.json)。

实测原始响应约 77%–78% 为负，轴和不为 1。**它们不是已校准概率，两个轴的外积也不自动成为正确的二维联合分布**；presence/visibility 保持未知。这一步只消除了信息被提前丢弃的接口障碍，尚未实现 MEOM、替换前端或证明三维精度提高。默认算法、控制门和固定环境不变。

## 下一轮按此顺序借鉴

1. **先解决观测。** 同框对照 RTMPose-M 与 PMPose，测二维位置、出框错误、存在性/可见性与二维 HDR 校准；再独立比较预测人物掩码、实例关联和分布融合。禁止把真值框/掩码混入自动链路。RTMPose 分布只能作为明确标注未校准的消融，不用 softmax 后冒充 ProbPose。
2. **再联合人体状态。** 以当前/历史图像证据联合求根部、旋转和可修订体型；密集表面点作为独立观测，先验/预测另标。保留 COCO17 不可观测的手脚朝向与轴向扭转，不将强先验当测量。因果时序候选与离线全序列教师分别评分。
3. **用同一评测决定是否启用。** 固定输入、模型/代码哈希和关节对应；比较全部目标成功率、共同有效点均值/P95、覆盖、>500 mm 错误、左右交换、恢复跳变、相位与截止时间内输出。按人物/动作留出并冻结后评分，分块统计配对差异；S4/S6 已见，只是回归集。缺旋转/接触独立真值时明确留空，不能拿伪标签验收自身。
4. **最后接全身控制对照。** 在原始人体参考上分别计模仿误差与可执行偏移，源腿部/骨盆保持步态来源。新策略须测试视觉缺失、延迟、接触误判和停止，不因轨迹更平滑就降低跟踪标准。真实曝光延迟、独立停止机制和 G1 实机绑定仍待硬件验证。

此次优先级是结合本项目失败记录作出的工程判断，不是论文作者结论。没有足够证据预测本项目将改善多少毫米，更不能承诺超越全部研究。
