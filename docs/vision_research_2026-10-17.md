# 多相机人体视觉姿态估计调研与优化方案

记录日期：2026 年 10 月 17 日。目标是无标记观察人的行走和全身动作，得到可供宇树 G1 EDU 重定向的连续人体状态。感知保持独立于 G1 的尺寸、关节限位和控制策略。人体模型对外观不同的人形机器人的适用性需要另行验证。

当前视觉前端已具备标定、多视角推理和鲁棒几何重建，但还未达到稳定机器人模仿的要求。主要缺口是观测不完整、骨架和时序约束不足，以及四路图像串行处理。更换二维模型只解决其中一部分。

## 当前实现和证据

实现入口是 `pose_sim/pipeline.py`。当前链路为四路已标定 RGB → YOLOX-M 人体检测 → RTMPose-M COCO17 → 逐关节加权 DLT 和相机对候选筛选 → 鲁棒重投影优化 → 三维关节点。每个视角仅接受恰好一个人的检测，没有多人身份关联。One Euro 滤波目前位于下游重定向中，视觉重建本身逐帧独立。

基线为 `outputs/human_walk_g1`，4 路 640×640 图像，24 FPS，96 帧。RGB 来自 CesiumMan 行走动画；推理不读取模型骨架或真值。

| 环节 | 当前问题 | 证据与边界 |
| --- | --- | --- |
| 采集同步与标定 | 真实曝光时钟、漂移、运动模糊和标定误差尚未验证 | 时间戳匹配已有回归；当前理想同步仿真不能证明真实设备同步性能，也不能把卡顿归因于同步 |
| 二维观测 | 每帧每视角独立推理；COCO17 缺少脚跟、脚趾和手掌信息 | 遮挡和左右混淆的具体来源仍需逐视角标注与消融 |
| 跨视角融合 | 按关节名字对应，没有整个人体的骨架一致性判断 | 两个错误观测可能产生低重投影误差；几何自洽不等于解剖正确 |
| 骨架与时序 | 没有源人体固定骨长模型与独立连续状态估计 | 右小腿长度变异系数 20.8%；下游拒绝 96 帧中的 10 帧 |
| 完整姿态 | 足部、手部完整朝向和接触状态缺失 | COCO17 无法直接观测这些自由度；不能用默认朝向冒充测量 |
| 效率与调度 | CUDA 推理仍串行处理四路，读图也串行 | 带性能分析和读图平均 121.37 ms/组，约 8.24 组/秒；不含采集、三维重建、显示延迟 |

基线 12 个身体代理点平均误差 60.87 mm、P95 131.54 mm，平均内点重投影误差 2.77 px。代理点是模型骨骼中心，与 COCO 解剖标注存在定义差异；该数字不是实拍人体精度。98.4% 关节点重建率也不是正确率。理想投影的几何自测仅验证代数与坐标变换。

当前协方差使用固定 2 px 独立各向同性噪声，未计入对应错误、标定和同步误差，不能解释为经实测校准的置信区间。GPU 算子已确认实际运行；8.24 组/秒是特定实现的测量，不是 RTX 4090 的硬件上限。

证据文件：`outputs/human_walk_g1/metrics.json`、`inference_timing.json`、`imitation/diagnostics.json`。机器人参考突变和回退机制也影响卡顿，应在视觉稳定后单独评估控制；视觉优化不等于全链路验收通过。

## 模块化优化顺序

1. 建立视觉基线与故障指标。固定相同 RGB 对照模型，记录逐关节覆盖、代理误差、骨长变动、跳变、遮挡恢复和延迟。独立评测才读取真值。后续增加转身、交叉步、下蹲、挥手和实拍遮挡数据。
2. 抽象二维模型与具名关键点接口，比较 RTMPose 和 RTMW。优先身体与足部，按质量决定是否使用手部信息。大模型作为后续候选，不在未测量时替换在线主模型。
3. 保留原始三角化输出，新建源人体骨架约束模块，估计人物骨长并抑制异常肢体。按关节处理局部失效，所有修正保留观测来源。
4. 新建独立因果时序状态模块。输出观测、估计、短时预测和未知状态，记录最后观测时间和不确定性；不读取未来帧、不无限外推。评估动态延迟，避免用过度平滑掩盖真实动作。
5. 从足跟和足趾观测估计足部朝向及接触候选；接触为概率或未知，需显式地面标定，不能假定脚永远贴地。肢体轴向扭转等不可观测量保留未知。
6. 优化 GPU 流水线：比较相机批处理或并发、减少重复解码、线程配置与数据传输。测量无性能分析开销的均值/P95；保留有限队列和过期规则。低维运动学是否迁移 GPU 由测量决定。

目标边界：采集同步 → 二维观测 → 跨视角关联和三维融合 → 人体结构及时序估计 → 标准人体状态 → G1 重定向。标准状态包含时间戳、米制世界坐标、具名关节、速度、可观测朝向、接触候选、来源和质量。人体尺寸与 G1 尺寸分别处理。

## 关键科学问题与验收

- **可观测性**：两条肢体方向不能唯一决定全部关节旋转；遮挡时的先验补全必须区别于图像测量。
- **关联和不确定性**：结合像素证据、跨视角一致性、骨架约束识别错误观测；经验置信度需要实拍数据校准。
- **连续性与延迟**：同时测误差、骨长变化、速度跳变、恢复时间和输出数据年龄。平滑的错误姿态不能通过验收。
- **形体与迁移**：估计源人体的形体参数；视觉输出不被 G1 限位扭曲。人形机器人外观需单独数据验证。
- **实机准备**：真实相机同步、标定、曝光与硬件延迟需实测。当前合成输入和软件回归不能代表相机或物理 G1 验收。

第一轮优化验收要求是同一输入上有可复现的精度、稳定性及耗时对照，且缺失、时间跳变、身份/标定变化不能产生伪造的新观测。24 组/秒仅为追上当前输入的最低吞吐目标，不能以此宣称整链路实时。后续验收门限由真实动作数据和机器人控制预算确定。

## 第二轮补充研究与采用边界（2026-10-17）

- [MAMMA，CVPR 2026 Oral](https://mamma.is.tuebingen.mpg.de/)：联合利用多视角稠密表面点、可见性、不确定性和接触拟合人体。对本项目的启发是把观测选择、人体尺寸和运动状态分开，同时让它们提供明确的约束。当前实现没有部署 MammaNet、SMPL-X，也没有复现论文精度。官方 [代码与公开四相机样例](https://github.com/cuevhv/mamma) 已核查；本地样例仅作非商业研究，不入库、不分发。
- [UPose3D，ECCV 2024](https://arxiv.org/abs/2404.14634)：将跨视角、时序及预测不确定性用于姿态编译。我们采用历史投影参与当前左右标签假设的选择，保留几何证据；没有训练论文网络。
- [Vision-Based Safe Human-Robot Collaboration with Uncertainty Guarantees，2026](https://arxiv.org/abs/2604.15221)：在独立校准集上校准预测误差范围，并监测分布变化。当前仅实现分序列最大归一化误差的经验校准和域/实现指纹检查，没有实现论文 OOD 网络或安全认证。来自同一程序生成器的序列不能被当成独立真人样本，覆盖率不作真实场景保证。
- TwinPose 的跨视角结构一致性为左右肢体组假设提供参考；当前是本项目的枚举几何实现，并非对官方算法或学习模型的完整复现。

采用原则：只在调参集决定配置，校准集只拟合误差尺度，测试集不用于选择阈值。软件缺陷修复后允许重跑原测试作为回归，但不把重跑说成新增独立证据。联合重投影优化在调参集未优于关联后重建，且增加约 5 ms，因此保留可选、默认关闭。所有视角同时发生左右互换时，几何本身不能唯一恢复语义，输出歧义而非声称恢复正确。

公开数据访问记录：Panoptic 官方地址（HTTPS/HTTP）与官方脚本列出的 SNU 镜像均连接失败；随后下载 MAMMA 官方无需登录的四相机样例，固定仓库提交 `588492f18876e2ed6888b2d26929047cb6b575e7`。该样例包含多人且无随附三维真值，不能替代定量真人动作评测。

## 进一步研究路线与回退诊断（2026-10-17）

用户希望推进到领先研究水平。可检验目标应限定为：固定相机、计算资源、允许使用的历史/未来帧和机器人控制器，在未见人物、动作组合、场景及相机条件上，改进精度、延迟、有效输出率和全身模仿结果。不存在由有限测试证明“超越任何研究、所有情况下最优”的方法；本项目目前也没有领先证据。以下为研究计划，不表示相应算法已经实现。

### 同一 RGB 检测结果上的因子消融

新增 [诊断报告](../reports/vision-rgb-ablation-2026-10-17.json)。固定 `outputs/vision_optimized/detections.jsonl` 的 96 帧、原标定和几何配置，关闭可选结构重投影；分别切换关联与人体状态。v1 状态仅通过适配器传递实际标定指纹，使其历史也能被关联模块使用。每条链路推理完成后才读取代理真值。

| 跨视角关联 | 人体状态 | 平均代理误差 mm | 身体当前观测点 / 预测点 / 缺失点 |
| --- | --- | ---: | --- |
| 原始标签 | v1 | 47.627 | 1106 / 40 / 6 |
| 新关联 | v1 | 49.357 | 1080 / 70 / 2 |
| 原始标签 | v2 | 48.763 | 1116 / 32 / 4 |
| 新关联 | v2 | 49.960 | 1092 / 59 / 1 |

该结果定位到关联和状态两处回退，尚不能把 v2 的影响单独归因于尺寸或速度反馈。各方法覆盖不同，平均误差按各自有效点统计；后续须同时报告共同观测集合误差、全目标失败率及逐事件变化，避免用丢点或预测补点改变平均数。原渲染样例已反复使用，只作开发诊断，不能再次称为独立测试。

### 要验证的研究假设

1. **保留观测多解能减少错误恢复。** 在二维层保留关键点分布、可见性和外观特征，在关联层保留少量人物/左右标签候选，在有界因果窗口内联合比较图像、相机几何、人体结构与运动证据。全视角语义歧义保留多解，不用历史先验制造观测。多人身份关联与左右标签关联分开评测。
2. **按不同时间尺度估计形体、姿态和偏差，能减少尺寸自锁及错误漂移。** 人体形体作为跨帧共享的慢变量，关节旋转和根部运动作为快变量；检测器的解剖定义差异和视角相关偏差单列。先固定可靠相机标定并传播其误差，避免同时放开标定、骨长、偏差后彼此抵消。共同系统偏差不可由重投影残差唯一分离，须通过可观测性检查扩大不确定性或保持未知。
3. **控制相关的误差分布能提高有效模仿时间。** 感知独立输出观测/推断来源、关联候选、位置与旋转不确定性、速度和接触候选；重定向适配器将误差传播到目标关节与落脚位置。测试在相同错误动作预算下，能否提高正确动作覆盖和任务完成率。始终停止、冻结足部或让机器人自行步行都不能算胜出。

统一人体状态的旋转在旋转群上更新，速度与位置在同一估计模型中保持一致，接触采用可切换的支撑假设。骨长、关节活动范围、地面和接触都是有误差的约束，不能无条件压住图像证据。稠密表面点或 SMPL-X 等人体模型可增强旋转观测，但网络补全的轴向旋转仍须标为先验推断。

### 本次补充核查的比较对象

- [COMETH，2026](https://github.com/PARCO-LAB/COMETH)：已有生物力学约束、凸优化融合和状态观测器。因此仅组合骨架约束与时序滤波不构成充分创新；应作为轻量融合基线。
- [TwinPose，SIGGRAPH 2026](https://github.com/HYPER-THEORY/TwinPose)：用于人物结构关联基线；[UPose3D](https://arxiv.org/abs/2404.14634) 用于跨视角、时序和不确定性基线；[TEMPO](https://arxiv.org/abs/2309.07910) 用于时空融合与效率比较。各实现必须核查是否使用未来帧，离线结果单列。
- [MAMMA，CVPR 2026](https://mamma.is.tuebingen.mpg.de/)：作为稠密点、形体与接触恢复的重要比较对象；其离线优化质量不能直接当作本机在线延迟成绩。官方参数人体参考也不等于全部解剖旋转的独立真值。
- [BeyondMimic](https://beyondmimic.github.io/) 和 [TWIST2](https://arxiv.org/abs/2511.02832)：用于下游完整运动跟踪与控制架构比较。TWIST2 使用 VR 输入，不能充当纯 RGB 视觉基线。先固定同一控制器比较视觉模块，再独立比较控制器。
- [Kinodynamic Motion Retargeting，2026](https://arxiv.org/abs/2603.09956)：为重定向阶段的多接触与动力学可行性提供研究参考，不作为已完成实机接入。
- [Vision-Based Safe Human-Robot Collaboration with Uncertainty Guarantees，2026](https://arxiv.org/abs/2604.15221)：借鉴独立校准与分布外检测；误差集合的覆盖不等于人形机器人平衡或硬件安全保证。

### 执行与验收顺序

1. 对当前关联修正、歧义拒绝、尺寸稳定状态和速度反馈做逐帧故障归因；补共同集合指标，新增针对真实失败模式的回归。先恢复已有完整 RGB 链路表现，避免按单一代理误差盲目调参。
2. 建立可复现前沿基线与独立真人测试。人物、录制场次、衣着和相机条件分组拆分；训练、调参、校准与最终测试互斥。合成数据只补充可控故障。自采保持无标记；公开数据的参考来源和 RGB 中是否可见标记单列，参考不可观测的指标留空。
3. 先实现可检查的多假设与人体状态联合估计，再评估学习式跨视角特征融合。一次只验证一个研究假设；大模型可作训练集上的离线候选教师，伪标签不能直接充当测试真值。
4. 固定本机 RTX 4090 评估精度与完整延迟曲线。用性能分析决定检测频率、跨相机批处理、缓存、异步传输及模型蒸馏；低维优化保留 CPU，迁移依实测。追上 24 组/秒为当前输入吞吐最低需求，真正曝光到状态的 P95 和控制允许的数据年龄单独测量。
5. 在同一 G1 模型和控制器上比较动作忠实度、接触顺序、落脚误差、脚滑、恢复、失稳及完整任务成功率。训练控制器时注入实测关联错误、丢帧、延迟与状态不确定性；步态仍由源腿部和骨盆驱动。硬件验证需具体设备、同步标定、反馈、限位及独立停止机制。

领先证据须来自统一输入及计算预算、无未来帧泄漏、冻结配置、跨数据集测试、按人物/序列重采样的统计区间和公开失败案例。位置、旋转、相位与脚滑的参考定义必须一致，不能通过对齐去掉世界根部误差，也不能通过拒绝困难帧取得虚假的平均精度优势。

### 无真实相机数据阶段的实施进展

用户确认暂时无法获得真实相机数据后，完成了关节对关联及局部歧义拒绝、暂定尺寸软约束、位置/速度状态一致性、共同集合评测、随机扰动独立比例测试、GPU batch-1 并发和 CPU 小规模几何求解优化。见 [第三轮模块说明](vision_pipeline.md#第三轮无真实相机数据条件下的修正) 与 [第三轮验收报告](../reports/vision-revision-2026-10-17.json)。

这些是可复验的工程和估计改进，尚未实现学习式跨视角特征融合、多假设轨迹后验或可验证的真实接触力恢复，也未复现前沿方法的完整模型；不能据此宣称超过前沿研究。实际人体数据、参考定义与传感器曝光验证仍保留为独立未完成项。
