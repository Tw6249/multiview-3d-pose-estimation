## 第二部分：仿真阶段（Simulation Phase）算法规范与测试验收标准

在仿真阶段，我们不需要真实相机和真实机器人。系统的输入源可以是 **多视角公开视频数据集（如 AIST++、Human3.6M）**，也可以是 **在仿真器（Blender/MuJoCo）中架设 4~6 个虚拟相机对虚拟人动画（AMASS 数据集）渲染出的多视角同步视频流**；系统的输出端直接驱动 **MuJoCo 中的宇树 G1（29 自由度模型）**。

全局坐标系约定：所有三维模块统一遵循机器人学右手系标准——**$+X$ 朝前，$+Y$ 朝左，$+Z$ 竖直向上，地面为 $Z=0$ 平面**。

### 模块 S1：2D 全身关键点提取与 3D 重投影切图追踪器

* **参考源码**：`Tau-J/rtmlib` 中的 `RTMPose` 类与 `PoseTracker` 类。
* **功能描述**：接收 $N$ 路（建议 $N=4 \sim 6$）同步视频帧及对应虚拟相机的精确内外参，输出每路画面中筛选后的 **“黄金 27 个关键点”** 的 2D 像素坐标与置信度。
* **算法细节与逻辑规范**：
  1. **关键点裁剪拓扑（27点）**：加载 `RTMW-m` 或 `RTMW-l`（输入分辨率 `256x192` 或 `384x288`）ONNX/TensorRT 模型。模型原始输出为 COCO-WholeBody 133 点，在输出层立即按索引切片保留 **27 个点**：
     * 身体主干 17 点（原始索引 `0~16`）；
     * 左右脚部刚性三角形 6 点（原始索引 `17:左大脚趾, 18:左小脚趾, 19:左脚跟, 20:右大脚趾, 21:右小脚趾, 22:右脚跟`）；
     * 左右手掌刚性三角形 4 点（原始索引 `96:左食指根MCP, 108:左小指根MCP, 117:右食指根MCP, 129:右小指根MCP`）。
     * 丢弃其余 106 个面部和手指细节点。
  2. **双模态追踪状态机（省去每帧目标检测）**：
     * **`DETECT_MODE`（全局检测态）**：在首帧或跟丢时触发，调用 `YOLOX-Nano` 或 `RTMDet-Nano` 检测出各视角下的人体 2D 包围盒。
     * **`TRACK_MODE`（3D 重投影追踪态）**：当上一帧成功重建出 $\ge 14$ 个有效 3D 关键点时进入此模式。利用恒速模型预测当前帧 3D 点集位置 $\hat{\mathbf{X}}_t = \mathbf{X}_{t-1} + \mathbf{V}_{t-1}\Delta t$，通过各相机的投影矩阵 $\mathbf{P}_c$ 投影回 2D 图像平面，取极值得到紧致包围盒，再将宽高乘以 **$1.35$ 倍膨胀系数（Padding）** 并强制对齐网络输入的 $3:4$ 宽高比，直接构造仿射变换矩阵切图送入 `RTMW` 批量推理（Batch Size = $N$）。
     * **跟丢回退机制**：若当前帧平均 2D 置信度 $< 0.45$ 或下一模块有效合成的 3D 点数 $< 14$，立即退回 `DETECT_MODE`。

#### 🧪 Agent 自动化测试方法与验收指标（模块 S1）
* **测试数据集构造**：使用 `AIST++` 数据集（自带多视角标定参数与 3D 真值）或使用 MuJoCo 渲染一段 10 秒（1000 帧）虚拟人做深蹲、挥手、转身动作的 6 视角视频。
* **量化验收指标**：
  1. **维度与索引正确性**：输出张量形状严格为 `(N_cams, 27, 3)`，最后一维为 `[u, v, confidence]`，无越界或全零通道。
  2. **追踪切图命中率**：在 1000 帧连续动作测试中，处于 `TRACK_MODE`（跳过目标检测器）的帧数占比应 **$\ge 98\%$**。
  3. **切图与全图一致性误差**：对比“开启 3D 重投影切图”与“每帧跑目标检测器”算出的 2D 关键点坐标，平均像素偏差（2D MPJPE）应 **$< 1.5\text{ pixels}$**。
  4. **推理耗时指标**：在单张支持 FP16 的 GPU 上，Batch=6 的 `RTMW` 端到端单步提取耗时应 **$< 6.0\text{ ms}$**。

### 模块 S2：多视角鲁棒 3D 三角测量与几何门控

* **参考源码**：`perfanalytics/pose2sim` 中的 `Pose2Sim/triangulation.py`（重点参考 `triangulate_points` 函数）。
* **功能描述**：将 $N$ 个相机的 `(N_cams, 27, 3)` 2D 关键点与相机投影矩阵 `(N_cams, 3, 4)` 合成为世界坐标系下的 `(27, 3)` 3D 关键点坐标。
* **算法细节与逻辑规范**：
  1. **置信度初筛**：对每个关键点 $j \in [0, 26]$，剔除 2D 置信度 $c_{i,j} < 0.35$ 的相机视角。若剩余可用相机数 $< 2$，该点当前帧标记为 `NaN`。
  2. **置信度平方加权 DLT（Direct Linear Transform）**：对每个参与相机 $i$，构造两条线性方程，并用置信度的平方 $w_i = c_{i,j}^2$ 加权，压制半遮挡边缘相机的权重，通过奇异值分解（SVD）求解齐次坐标 $\mathbf{X}$。
  3. **两轮重投影残差剔除（抗遮挡核心）**：
     * 第一轮 SVD 算出初始 3D 点后，将其重投影回所有参与相机的 2D 平面，计算像素重投影误差 $e_i = \|\mathbf{u}_{\text{proj}, i} - \mathbf{u}_{\text{det}, i}\|_2$。
     * 若存在相机 $e_i > 15.0\text{ pixels}$（说明该相机视角被身体遮挡或左右腿混淆），剔除超标相机（若全部超标则剔除误差最大的那 1 个相机），只要剩余相机数 $\ge 2$，立即执行第二轮 SVD 精解。
  4. **帧间最大位移门控（防飞点）**：对比当前帧算出的 3D 点与上一帧位置，若单帧（以 $100\text{ Hz}$ 计，即 $10\text{ ms}$）欧氏距离跳变 $> 0.25\text{ m}$（对应非人类的 $25\text{ m/s}$ 瞬时速度），判定为多视角联合奇异飞点，强制将该步位移幅值截断（Clamp）在 $0.25\text{ m}$ 以内。
  5. **性能加速要求**：由于需要在 27 个点上跑循环 SVD，Agent **必须使用 `Numba (@njit)` 或 C++ 扩展** 编译该模块，严禁使用纯 Python 原生慢速循环。

#### 🧪 Agent 自动化测试方法与验收指标（模块 S2）
* **合成基准测试法（Synthetic Unit Test）**：
  Agent 编写一个自动化测试脚本：在三维空间生成已知真值（Ground Truth）的 27 点人体骨架序列，通过 6 个已知相机矩阵投影生成理想 2D 点，然后人为注入以下三重干扰：
  1. 对所有 2D 点叠加 $\sigma = 2.0\text{ pixels}$ 的零均值高斯噪声；
  2. 随机挑选 1~2 个相机，将其左腕、右膝的 2D 坐标人为偏移 $120\text{ pixels}$（模拟严重遮挡与左右互换坏点），但仍赋予 $0.8$ 的高欺骗置信度；
  3. 在第 50 帧人为将所有点偏移 $2.0\text{ m}$（模拟单帧闪现干扰）。
* **量化验收指标**：
  1. **抗遮挡还原精度**：在存在 1~2 个相机发生 $120\text{ pixels}$ 严重离群错误的条件下，算出的 3D 坐标与真值的平均绝对误差（3D MPJPE）必须 **$< 8.0\text{ mm}$**（证明重投影剔除算法生效）。
  2. **飞点拦截有效性**：在第 50 帧的单帧 $2.0\text{ m}$ 突变注入下，输出点单帧位移严格 **$\le 0.25\text{ m}$**。
  3. **计算耗时指标**：经 Numba/C++ 加速后，6 相机 27 点的完整两轮 SVD 求解平均耗时必须 **$< 0.5\text{ ms}$**（预热后）。

### 模块 S3：时序抗抖滤波与足端“软解锁”物理接触滤波器

* **参考源码**：`perfanalytics/pose2sim` 中的 `Pose2Sim/filtering.py`（`one_euro_filter`）。
* **功能描述**：接收模块 S2 输出的原始 3D 关键点流，消除高频闪烁噪声，并强制消除足端悬空、穿地与水平滑步（Foot Skating），同时保证抬脚解锁瞬间的速度连续性。
* **算法细节与逻辑规范**：
  1. **向量化一欧元滤波（One-Euro Filter）**：
     * 缺失值补全：若某点当前帧为 `NaN`，先用上一帧滤波状态填充。
     * 动态截止频率公式：$f_c = f_{c_{\min}} + \beta \cdot |\hat{\dot{\mathbf{X}}}|$。推荐默认参数：采样率 $f = 100\text{ Hz}$，最小截止频率 $f_{c_{\min}} = 1.2\text{ Hz}$，速度斜率系数 $\beta = 0.04$，导数截止频率 $f_{c_d} = 1.0\text{ Hz}$。
  2. **施密特触发器双阈值触地检测（Hysteresis Contact Detection）**：
     * 针对左脚四点 `[15:左踝, 17:左大脚趾, 18:左小脚趾, 19:左脚跟]` 和右脚四点 `[16:右踝, 20:右大脚趾, 21:右小脚趾, 22:右脚跟]` 独立维护接触状态 `in_contact`（布尔值）。
     * **进入触地锁死条件（`False -> True`）**：当脚趾与脚跟的最低离地净高度 $z_{\min} < 0.03\text{ m}$（扣除静止站立时标定的鞋底基准厚度 $z_{\text{nominal}}$）**且** 足端三维合成速度 $\|\mathbf{v}_{\text{foot}}\|_2 < 0.15\text{ m/s}$ 时，判定触地，记录当前帧四点的水平坐标作为地面锚点 $\mathbf{P}_{\text{anchor}}$。
     * **脱离触地解锁条件（`True -> False`）**：当 $z_{\min} > 0.05\text{ m}$ **或** $\|\mathbf{v}_{\text{foot}}\|_2 > 0.30\text{ m/s}$ 时，解除触地锁定，并启动一个长度为 $K = 6$ 帧（对应 $60\text{ ms}$）的软解锁过渡计数器。
  3. **锚点锁死与余弦软解锁过渡（Soft-Unlocking Blending）**：
     * 当 `in_contact == True` 时：足端四点的水平 $(X, Y)$ 坐标严格锁死在 $\mathbf{P}_{\text{anchor}}$ 上，垂直 $Z$ 坐标向基准高度做强阻尼吸附。
     * 当刚脱离触地、处于 $K=6$ 帧过渡期内时：**严禁直接跳回当前视觉测量点 $\mathbf{P}_{\text{raw}}$**（否则会在 1 帧内产生数米每秒的阶跃速度脉冲，导致下游 RL 控制器炸机）。必须按余弦曲线计算过渡权重 $\alpha_k = \frac{1}{2}\left(1 - \cos\left(\pi \frac{k}{K}\right)\right), k \in [1, K]$，输出位置 $\mathbf{P}_{\text{out}} = (1 - \alpha_k)\mathbf{P}_{\text{anchor}} + \alpha_k \mathbf{P}_{\text{raw}}$。
     * **防穿地硬约束**：任何时刻，足端四点的 $Z$ 坐标严格截断在 $\ge z_{\text{nominal}}$。

#### 🧪 Agent 自动化测试方法与验收指标（模块 S3）
* **测试信号构造**：
  1. **静态+动态混合轨迹**：构造一段前半段（0~2秒）完全静止、后半段（2~4秒）做 $3\text{ Hz}$ 正弦大幅度挥手及迈步的 3D 轨迹，叠加幅值为 $15\text{ mm}$ 的高斯白噪声。
  2. **足端漂移与解锁阶跃测试**：模拟脚踩地期间（0~1秒）视觉输入发生 $4\text{ cm}$ 的缓慢水平漂移，然后在 $t = 1.00\text{ s}$ 突然以 $0.5\text{ m/s}$ 向上抬脚触发解锁。
* **量化验收指标**：
  1. **静态噪声抑制比**：在 0~2 秒静止段，滤波后信号的标准差（Jitter RMS）相比输入噪声应下降 **$\ge 80\%$**（即残余抖动 **$< 3.0\text{ mm}$**）。
  2. **高速动态跟随延迟**：在 $3\text{ Hz}$ 快速运动段，滤波轨迹相对于无噪真值轨迹的峰值相位延迟应 **$< 15.0\text{ ms}$（即 $< 1.5$ 帧）**。
  3. **触地零滑移验证**：在 `in_contact == True` 期间，尽管视觉输入漂移了 $4\text{ cm}$，输出足端水平位移必须 **严格等于 $0.0\text{ mm}$**，且无任何一帧 $Z < z_{\text{nominal}}$。
  4. **软解锁速度连续性（核心指标）**：在 $t = 1.00\text{ s}$ 触发解锁后的连续 10 帧内，通过有限差分计算输出足端轨迹的帧间最大瞬时速度 $\|\mathbf{v}_{\text{out}}\|_{\max}$ 必须 **$< 1.2\text{ m/s}$**（若无软解锁，直接跳变 $4\text{ cm}/10\text{ ms}$ 会产生 $4.0\text{ m/s}$ 以上的尖峰脉冲）。

### 模块 S4：解析几何 $SE(3)$ 局部坐标系构建与分层形态缩放器（核心桥接层）

* **参考源码与理论依据**：结合 `YanjieZe/GMR` 中对人体骨骼旋转与位置的定义，以及 `HybrIK` 中的解析几何正交化思想。
* **功能描述**：将模块 S3 输出的人体尺度 27 个 3D 坐标散点 $\mathbb{R}^{27 \times 3}$，实时解析转换为宇树 G1 机器人尺度的 **10 个核心部位的 $SE(3)$ 目标位姿（含 3D 位置 $\mathbf{p} \in \mathbb{R}^3$ 与三维旋转四元数 $\mathbf{q}_{wxyz} \in SO(3)$）**，以此作为 `Mink` 求解器的输入。
* **算法细节与逻辑规范**：
  1. **形态感知分层骨长缩放（Morphology-Aware Hierarchical Scaling）**：
     * 从宇树 G1 的 MJCF/URDF 文件（如 `g1_29dof.xml`）中读取机器人真实物理连杆长度常量：骨盆站立高度 $H_{\text{pelvis}}$、髋半宽 $W_{\text{hip}}$、大腿长 $L_{\text{thigh}}$、小腿长 $L_{\text{calf}}$、躯干长 $L_{\text{torso}}$、肩半宽 $W_{\text{shldr}}$、上臂长 $L_{\text{uarm}}$、前臂长 $L_{\text{farm}}$。
     * **根节点缩放**：人体骨盆中心 $\mathbf{p}_{\text{pelvis}}^H = \frac{1}{2}(\mathbf{p}_{\text{l\_hip}}^H + \mathbf{p}_{\text{r\_hip}}^H)$ 乘以全身根缩放比 $\gamma = H_{\text{pelvis}}^{\text{robot}} / H_{\text{pelvis}}^{\text{human}}$，得到机器人目标骨盆位置 $\mathbf{p}_{\text{pelvis}}^R$。
     * **自顶向下运动学链向量重缩放**：严禁直接用人体世界坐标去吸引机器人四肢！必须计算人体父子关节间的**单位方向向量** $\vec{u}_{\text{parent}\to\text{child}} = \text{normalize}(\mathbf{p}_{\text{child}}^H - \mathbf{p}_{\text{parent}}^H)$，然后沿着运动学树（`骨盆 -> 髋 -> 膝 -> 踝` 以及 `骨盆 -> 胸腔 -> 肩 -> 肘 -> 腕`）依次乘以机器人对应连杆长度 $L^{\text{robot}}$ 累加计算出各关节在机器人尺度下的目标 3D 位置。
  2. **格拉姆-施密特正交化（Gram-Schmidt）构建局部旋转矩阵 $\mathbf{R} \in SO(3)$**：
     * **骨盆（Pelvis）与胸腔（Torso）**：以 `右髋 -> 左髋`（或 `右肩 -> 左肩`）单位向量作为局部 $+Y$ 轴；结合脊柱向上向量 $\vec{v}_{\text{spine}} = \text{normalize}(\mathbf{p}_{\text{neck}}^H - \mathbf{p}_{\text{pelvis}}^H)$，计算 $+X = \text{normalize}(+Y \times \vec{v}_{\text{spine}})$，$+Z = +X \times +Y$。
     * **左右脚掌（Left/Right Foot）**：利用脚部刚性三角形（脚跟、大脚趾、小脚趾）。以 `脚跟 -> 双趾中点` 单位向量作为局部 $+X$ 轴（朝前）；左脚以 `大脚趾 -> 小脚趾`、右脚以 `小脚趾 -> 大脚趾` 作为向左的横向参考向量 $\tilde{\mathbf{y}}$；计算 $+Z = \text{normalize}(+X \times \tilde{\mathbf{y}})$，$+Y = +Z \times +X$。
       * *法向防翻转保护*：校验 $+Z \cdot (\mathbf{p}_{\text{ankle}}^H - \mathbf{p}_{\text{heel}}^H) > 0$，若小于 0（极罕见的关键点交叉误检），立即将 $+Y, +Z$ 轴同时取反，确保脚底永远朝下且保持右手系。
     * **左右手掌（Left/Right Hand）**：利用手掌刚性三角形（手腕、食指根 MCP、小指根 MCP）。以 `手腕 -> 双指根中点` 作为局部 $+X$ 轴（沿手掌向前），左掌以 `小指根 -> 食指根`、右掌以 `食指根 -> 小指根` 作为参考向量 $\tilde{\mathbf{y}}$，正交化生成三维旋转四元数（直接约束宇树 G1 的 `wrist_roll`、`wrist_pitch`、`wrist_yaw`）。
     * **膝盖与手肘中间点**：仅输出缩放后的 3D 目标位置 $\mathbf{p}$，旋转四元数设为 `None`（作为纯位置引导点防止 IK 肘膝反向折叠）。

#### 🧪 Agent 自动化测试方法与验收指标（模块 S4）
* **数学不变量与几何单元测试（Automated Math Invariant Test）**：
  1. **特殊李群 $SO(3)$ 合法性测试**：随机生成 1000 组人体姿态（含深蹲、弯腰 90 度、原地旋转 360 度、单腿独立），检验输出的所有旋转矩阵 $\mathbf{R}$ 及四元数 $\mathbf{q}$：
     * 正交性误差 $\|\mathbf{R}^\top \mathbf{R} - \mathbf{I}\|_F < 10^{-6}$；
     * 行列式严格满足 $\det(\mathbf{R}) = +1.0 \pm 10^{-6}$（绝对不能出现 $\det(\mathbf{R}) = -1$ 的左手系镜像翻转）；
     * 四元数模长 $\|\mathbf{q}\|_2 = 1.0 \pm 10^{-6}$，且无任何 `NaN` 或 `Inf`。
  2. **跨体型骨骼长度守恒性验证**：输入一个身高 $1.90\text{ m}$ 和一个身高 $1.55\text{ m}$ 的人体 3D 骨架，验证经过模块 S4 转换后，输出的 `hip -> knee`、`knee -> ankle`、`shoulder -> elbow`、`elbow -> wrist` 欧氏距离**必须恒定等于宇树 G1 的物理连杆长度**（误差 $< 0.1\text{ mm}$）。
  3. **T-Pose 零位对齐测试**：当输入标准人体 T-Pose（面朝 $+X$，双臂向 $\pm Y$ 平举）时，输出的骨盆、胸腔、双足姿态四元数与单位四元数 $[1, 0, 0, 0]$ 的角度偏差应 **$< 3.0^\circ$**。

### 模块 S5：基于 `Mink` / `GMR` 的差分 QP 逆运动学与自碰撞防护

* **参考源码**：`kevinzakka/mink`（`examples/humanoid_g1.py`） 与 `YanjieZe/GMR`（`general_motion_retargeting/motion_retarget.py`）。
* **功能描述**：加载宇树 G1（29 自由度）MJCF 模型，接收模块 S4 的 $SE(3)$ 目标字典，在每个时间步 $\Delta t = 0.01\text{ s}$ 构建并求解二次规划（QP）问题，输出无自碰撞、不超限的机器人广义坐标 $\mathbf{q} \in \mathbb{R}^{36}$（含浮动基座 7 维 + 29 个关节角）与广义速度 $\dot{\mathbf{q}} \in \mathbb{R}^{35}$（含基座线速度/角速度 6 维 + 29 个关节角速度）。
* **算法细节与任务权重配置规范**：
  1. **多目标 `FrameTask` 权重分级**：
     * **双足末端（`left/right_ankle_roll_link`）**：最高优先级，位置权重 `pos_cost = 30.0`，姿态权重 `ori_cost = 15.0`（确保严格踩住地面锚点且脚底放平）。
     * **骨盆基座（`pelvis`）**：`pos_cost = 15.0`，`ori_cost = 20.0`。
     * **胸腔（`torso_link`）**：`pos_cost = 5.0`（低位置权重，释放腰部 3 个自由度去适应重心），`ori_cost = 15.0`（强姿态权重，还原俯仰与扭腰）。
     * **双手腕（`left/right_wrist_yaw_link`）**：`pos_cost = 15.0`，`ori_cost = 8.0`。
     * **双膝与双肘中间引导点（`left/right_knee_link`, `left/right_elbow_link`）**：`pos_cost = 4.0`，`ori_cost = 0.0`（仅用轻量位置牵引，确保手臂与腿部的弯曲平面与人类一致）。
  2. **零空间姿态正则化（`PostureTask`）与预屈膝偏置**：
     * 添加全局 `PostureTask`（权重 `cost = 0.1`），目标姿态设为宇树 G1 的标准微屈膝站立姿态（左右膝关节预弯曲约 $0.25\text{ rad}$），防止直立时陷入奇异锁死位形。
  3. **硬约束（`Limits`）与自碰撞避免**：
     * 挂载 `ConfigurationLimit`（关节角度软限位，增益 `0.95`）与 `VelocityLimit`（电机最大转速限幅）。
     * 挂载 `CollisionAvoidanceLimit`：配置碰撞几何体对 `[(左手, 右手), (双手/前臂, 胸腔/骨盆), (左小腿, 右小腿)]`，设定最小安全排斥距离 `minimum_distance = 0.03 m`。
  4. **求解器选型**：指定 `solver="daqp"` 或 `"proxqp"`，Levenberg-Marquardt 阻尼 `damping = 1e-3`。

#### 🧪 Agent 自动化测试方法与验收指标（模块 S5）
* **测试案例构造**：向模块 S5 输入三组极具挑战性的连续轨迹：① 深蹲起立 + 扭腰；② 双手用力拍手并交叉抱胸（故意触发人体手部穿透胸腔的目标）；③ 快速高抬腿迈步。
* **量化验收指标**：
  1. **关节限位合规率**：在整个测试序列中，29 个关节角超出 URDF `[lower, upper]` 物理限位的帧数占比必须 **$= 0.0\%$**。
  2. **自碰撞拦截有效性**：在“双手交叉抱胸”与“双腿并拢”压力测试下，调用 MuJoCo `mj_collision` 检测全身碰撞几何体间的最小有符号距离（Signed Distance），必须全程 **$\ge 2.5\text{ cm}$**（零穿透）。
  3. **末端跟踪精度**：在非碰撞受限区域，机器人双足与双手腕的实际正向运动学（FK）位置与模块 S4 目标位置的平均跟踪误差应 **$< 15.0\text{ mm}$**，姿态跟踪误差 **$< 4.0^\circ$**。
  4. **求解耗时指标**：使用 `daqp` 求解器时，单步 `solve_ik + integrate` 的平均 CPU 耗时必须 **$< 1.8\text{ ms}$**。

### 模块 S6：MuJoCo 双阶段仿真闭环验证（运动学重放 vs. 物理动力学 RL 闭环）

* **参考源码**：`unitreerobotics/unitree_mujoco`、`YanjieZe/TWIST`、`unitreerobotics/unitree_rl_lab`。
* **功能描述**：将前面 S1~S5 串联生成的机器人参考运动轨迹 $(\mathbf{q}_{\text{ref}}, \dot{\mathbf{q}}_{\text{ref}})$ 送入 MuJoCo 仿真器，分两个递进阶段完成闭环验收。
* **两阶段仿真测试流程规范**：
  1. **阶段 6A：纯运动学重放仿真（Kinematic Replay）**
     * 在 MuJoCo 中直接将每帧的 $\mathbf{q}_{\text{ref}}$ 赋值给 `mjData.qpos`，调用 `mujoco.mj_forward(model, data)`（不积分动力学），利用 `mujoco.viewer` 或离屏渲染视频。
     * *目的*：纯粹检验视觉动捕与运动重定向的几何质量（是否有肉眼可见的抖动、脚底是否像钉子一样钉在地面上、手腕旋转是否自然）。
  2. **阶段 6B：物理动力学强化学习闭环仿真（Physics-Based RL WBC Tracking）**
     * 开启完整的 MuJoCo 物理引擎（重力 $g = -9.81\text{ m/s}^2$、地面接触摩擦、电机扭矩限制与 PD 控制器 $K_p, K_d$）。
     * 加载开源预训练的宇树 G1 全身运动跟踪 RL 策略（可直接加载 `TWIST` 开源的通用 Motion Tracker Checkpoint 或 `unitree_rl_lab` 中的 `G1-29dof Mimic` 策略 ONNX 模型）。
     * 将模块 S5 实时流式输出的参考状态按照 RL 策略要求的观测空间（Observation Space：包含目标关节角偏差、目标根姿态/速度、本体 IMU 重力投影、历史动作等）打包输入给策略网络，以 $50\text{ Hz}$ 输出目标关节位置指令，由底层 $500\text{ Hz}/1000\text{ Hz}$ PD 控制器计算电机力矩 $\boldsymbol{\tau} = K_p(\mathbf{q}_{\text{policy}} - \mathbf{q}) - K_d\dot{\mathbf{q}}$ 驱动仿真机器人。

#### 🧪 Agent 自动化测试方法与验收指标（模块 S6 —— 仿真总验收）
* **量化验收指标**：
  1. **动力学平衡存活率（Survival Rate）**：在跑完 10 段不同动作（挥手、深蹲、原地踏步、行走、弯腰捡物，每段 10 秒）的物理闭环仿真（阶段 6B）中，机器人不摔倒（骨盆高度始终 $> 0.45\text{ m}$ 且倾斜角 $< 45^\circ$）的成功率应 **$= 100\%$**。
  2. **全身关节跟踪误差（Joint Tracking MPJPE）**：物理仿真中机器人实际关节角 $\mathbf{q}_{\text{sim}}$ 与模块 S5 参考关节角 $\mathbf{q}_{\text{ref}}$ 的均方根误差（RMSE）应 **$< 0.12\text{ rad}$（约 $6.8^\circ$）**。
  3. **物理足端滑移指标（Foot Skating Metric）**：在阶段 6A 和 6B 中，统计支撑脚（承受地面法向接触力 $F_z > 20\text{ N}$ 的脚）的水平平均滑移速度，必须 **$< 0.04\text{ m/s}$**。
  4. **电机扭矩平滑度**：相邻控制步（$20\text{ ms}$）之间的电机输出力矩变化率无高频极限震荡（验证模块 S3 的一欧元滤波与软解锁成功消除了 RL 控制器的高频抽搐）。

## 第三部分：实物阶段（Real-World Phase）工程扩展与安全验收规范（后续阶段）

当上述 **模块 S1 ~ S6** 在仿真中全部通过自动化测试后，算法核心（模块 S2 ~ S5）**无需修改一行数学逻辑**，只需在外围包裹以下 4 个硬件接口与安全模块即可平滑过渡到宇树 G1 真机：

### 模块 R1：多路工业相机硬件同步（Genlock）与零拷贝采集
* **工程规范**：采购 4~6 台全局快门工业相机，通过 GPIO Line0 引脚并联接入外部 $100\text{ Hz}$ 硬件脉冲发生器（STM32），相机手动曝光时间锁死在 **$\le 2.0\text{ ms}$**。采集端使用相机厂商 SDK（如海康 MVS SDK）在回调函数中直接将图像帧推入固定内存（Pinned Memory），并在 GPU 显存内完成仿射切图与归一化。
* **测试方法与验收指标**：
  * **同步精度测试**：将 6 台相机同时对准一个以 $1000\text{ Hz}$ 刷新的高精密数码毫秒表（或高速旋转编码 LED 灯盘）连续抓拍 1000 组图像。6 台相机在同一帧号下拍到的时间戳读数必须 **$100\%$ 完全一致（帧间同步误差 $< 1.0\text{ ms}$，零丢帧）**。

### 模块 R2：物理空间标定与地面 $Z=0$ 平面强制对齐
* **参考工具**：`perfanalytics/pose2sim` 中的 `calibration.py` 或 `Anipose` / `ChArUco` 标定工具链。
* **工程规范**：完成多相机内外参标定后，必须将标定板平铺在真实场地地面中央，采集地面角点拟合物理地面法向量，通过刚体变换矩阵修正所有相机的外参 $[\mathbf{R}_c | \mathbf{t}_c]$，使得世界坐标系的 $Z=0$ 平面严格贴合物理地板。并在每次操作员上场时，采集 0.5 秒静止站立数据自动更新模块 S3 的鞋底厚度基准值 $z_{\text{nominal}}$。
* **测试方法与验收指标**：
  * **地面平坦度与重投影验收**：全场地多相机标定平均重投影误差 **$< 0.8\text{ pixels}$**；将标定板放置在场地中心及四角地面上，三角测量算出的标定板角点 $Z$ 坐标绝对值偏差必须 **$< 3.0\text{ mm}$**。

### 模块 R3：多进程无锁共享内存架构与 `unitree_sdk2` (DDS) 对接
* **参考源码**：`unitreerobotics/unitree_sdk2`、`unitreerobotics/unitree_sdk2_python` 以及 `YanjieZe/TWIST` 中的 `sim2real` 部署脚本。
* **工程规范**：
  * 为彻底规避 Python GIL 导致控制周期抖动，系统拆分为独立进程：**进程 1（视觉与 Mink IK 进程，$100\text{ Hz}$）** 与 **进程 2（RL WBC 控制与 DDS 通信进程，严格实时循环）**。
  * 两个进程之间通过 `multiprocessing.shared_memory`（配合序列锁 Seqlock 或双缓冲区）传递 73 维参考状态数组与 64 位微秒级时间戳。
  * 进程 2 通过宇树 G1 专用的 `unitree_hg` IDL 消息格式（`LowState` 读取电机与 `rt/secondary_imu` 躯干 IMU 状态，`LowCmd` 下发电机 PD 目标） 与真机通信。
* **测试方法与验收指标**：
  * **控制环路抖动（Jitter）测试**：在满负载运行视觉推理的同时，记录进程 2 连续 10,000 次控制循环的时间间隔 $\Delta t$。要求平均周期偏差 **$< 0.2\text{ ms}$**，$99.9\%$ 分位最大单次卡顿（P99.9 Latency） **$< 2.0\text{ ms}$**。

### 模块 R4：真机安全护栏（软离合啮合、看门狗熔断与吊架测试流程）
* **工程规范**：
  1. **软离合平滑啮合（Soft Clutch Engage）**：真机启动遥操作时，严禁将关节参考指令直接切向当前视觉输出。必须经过 $T = 2.0\text{ s}$ 的线性插值过渡期，让参考轨迹从机器人的初始站立姿态平滑过渡到实时动捕姿态。
  2. **双层看门狗熔断（Watchdog）**：
     * **通信超时熔断**：若共享内存中的视觉时间戳滞后当前系统时间 $> 35\text{ ms}$，立即判定视觉管线卡死，自动切断增量跟踪，平滑阻尼锁死在当前安全站立姿态。
     * **关节速度跳变熔断**：若相邻两帧（$10\text{ ms}$）输入的参考关节角最大差值 $\max |\Delta \mathbf{q}_{\text{ref}}| > 0.35\text{ rad}$（约 $20^\circ$），判定发生视觉极端异常，立即触发阻尼保持（Hold Pose）。
* **真机上电验收流程**：
  * **第一步（悬空吊架测试）**：将宇树 G1 悬挂在龙门保护吊架上（双脚离地 $10\text{ cm}$），验证四肢跟随方向、手腕正反转、腰部俯仰与紧急熔断开关（拔掉相机线测试看门狗是否在 $35\text{ ms}$ 内平滑停机）。
  * **第二步（地面保护绳测试）**：放下吊架，在保护绳微松状态下完成站立啮合、深蹲、上肢遥操作及踏步测试。
