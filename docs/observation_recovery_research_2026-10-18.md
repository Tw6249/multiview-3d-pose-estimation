# 错误/缺失观测的识别、恢复与连续接续

日期：2026-10-18。用户问题：“错误或缺失观测如何被可靠识别和恢复，同时避免轨迹跳变。”本轮为原文、官方代码入口及现有实现核查；以下方案尚未实现或取得新的算法收益。

核心判断：把**观测是否可信、状态如何恢复、机器人如何接续**分成三个问题。新证据可能要求立即纠正错误估计；机器人参考应从当前已输出状态连续过渡。全部视角都看不到时，不能同时保证真实动作恢复、零等待和无误差，只能保留预测范围及未知量。

## 现有项目的具体缺口

| 环节 | 已有能力 | 尚未解决的问题 |

## 建议的模块化方案

下表是待验证设计。公共约定：图像坐标为原图像素，人体状态使用标定世界系（m、m/s、m/s²、rad、rad/s），源曝光时间为整数 ns；机器人使用具名关节与模型哈希。保留来源、原观测时间、预测时域及校准版本。不得把预测写成新曝光观测。

| 模块 | 输入 → 输出 | 失败行为与关键验证 |
| --- | --- | --- |
| 观测风险 | 二维候选/分布、图像轨迹、同步/标定及留一视角残差 → 每关节每视角的可信、矛盾、缺失或未知证据 | 同步/标定异常按相机或整包诊断，不全归咎于肢体。以误接收率、误拒绝率、风险—覆盖曲线验证，不能只看重投影误差。 |
| 多假设重建 | 当前证据、软体型分布及历史状态 → 少量具名人体候选及其支持来源 | 历史只作软约束；至少保留一个不依赖旧轨迹的当前观测候选。左右/人物假设不足以区分时输出歧义，不把互斥姿态平均成不存在的肢体。 |
| 恢复管理 | 候选随曝光时间的连续证据 → 跟踪、降级、丢失、候选、确认状态 | 短缺失仅作有界预测，超过期限转未知；恢复后逐段确认身份、肢体结构、速度与不确定性。确认时间用校准集选择并计入延迟，不把“三帧连续”当普适证明。 |
| 风险校准 | 冻结估计器与独立校准序列 → 位置/速度/旋转误差集合及适用范围 | 分人物、可见视角数、遮挡长度审计覆盖。校准样本不足、分布变化或集合过大时不许可精细跟踪；单点覆盖不能替代全身联合风险。 |
| 参考接续 | 已确认人体状态、重定向目标、当前已输出参考及机器人反馈 → 连续参考/过渡状态 | 从当前参考的位置、速度、加速度重规划；反馈用于可行性与跟踪偏差检查，不能直接硬重置参考。接触/限位/平衡不可行时交给退出层，行走中不能简单冻结全部关节。 |

恢复顺序应是：**同一时刻其他视角的证据 → 图像时序与人体结构共同消歧 → 短时带不确定性的预测 → 未知**。可以并行产生候选，但禁止以先验补全替代已有的新图像证据。持续几帧的错误并不因“平滑、骨长合理”而成为正确。

避免跳变分两层验收：人体估计保留真实纠错量与状态切换；机器人参考要求位置/速度/加速度连续，且导数受限。旋转在 SO(3) 上处理，不能直接跨 ±π 平均欧拉角。切换时还需同侧支撑和源腿相位一致，不能为了平滑改成独立步态。

## 先建立能否证方法的恢复评测

1. **事件而非零散帧。** 从现有 RGB 标注可见→遮挡→再出现、左右交叉、转身、快速摆臂、蹲起和人物干扰；标注人、相机、肢体、曝光区间与标注不确定性。出画、真实遮挡、检测漏检、几何退化分别记录，不能把“投影在画面内”当可见真值。
2. **注入压力测试单独报告。** 固定随机种子注入单/多视角丢失、100/300/600 ms 缺口、高分错点、单视角与全视角左右互换、时间偏移和标定扰动。实际缺帧数/时长必须按源时间计量。注入标签只标识故障，不证明其余检测正确；二维缓存注入也不等于真实 RGB 遮挡实验。
3. **保持独立性。** 开发、校准、测试按人物/完整序列隔离，并对时间块统计置信区间。现有 S4/S6 已多轮查看，只是历史复验集；新算法不能据此声称未见泛化，需预留尚未查看的序列/数据源。
4. **联合验收。** 固定全部目标分母，报告缺失率、错误接受率、恢复耗时、恢复后身份错误率、位置/速度/可观测旋转误差、相位延迟和动作幅度。跳变用 `(估计位移 − 参考位移)` 的误差衡量，纳入重新初始化和缺失后再出现；真实快速运动不应被当成抖动惩罚。另测参考连续性、脚滑/接触与动力学成功，但后两者当前缺独立人体参照。

借鉴 AJ_RD 的“按缺失持续时间分层、检查重新出现后是否持续正确”，并增加人体左右身份指标；这属于本项目评测扩展，不能把改编指标当论文原指标。使用未来帧的方法必须另列：例如 25 Hz 下等待两帧就增加 80 ms，不能只报网络推理时间。

## 实施优先级与本轮边界

- 第一轮：冻结当前基线，补事件标签和失败注入；校准 PMPose 的位置风险并查清覆盖损失。先获得可解释的错误接受/拒绝基线。
- 第二轮：在相同二维输入上比较点式融合、分布融合及独立恢复候选；再增加 TAPNext++ 图像轨迹，避免多项一起改而无法归因。GPU 用于图像前端/跟踪，低维几何继续按实测决定。
- 第三轮：通过恢复验收后连接现有参考接续层，联合检查纠错量、相位延迟、左右对应和 G1 动力学。感知改善不能自动算成机器人成功。

## 第一轮实施：恢复事件评测与轨迹确认（2026-10-18）

**做了什么。** 新增 [故障注入](../pose_sim/fault_injection.py)：在缓存的二维检测上按固定种子注入 7 类带标签故障（单视角丢失、单肢全视角丢失、全身缺口、单视角高分错点、单视角/全视角左右互换、单视角时间错位），时长 100/300/600 ms，每 3 s 一个事件，不读参考真值。[事件评测](../scripts/benchmark_recovery_events.py)让每种方法先跑干净数据、再跑注入数据，按事件配对计分；自然事件取“可用视角 <2”及“参考点在画面内的相机 <2”两种。人体状态增加可选的轨迹确认 `track_confirmation_frames`：新建或过期重建的关节先标为 `tentative`，连续被接受 N 帧后才输出 `filtered`；未确认关节不参与骨长、朝向和接触估计。默认 N=1，与原行为逐字段一致。

**开发集结果（S1/S2，54 个注入事件，3 个种子）。**

| 指标 | 默认 N=1 | N=2 | N=3 |
|---|---|---|---|
| 注入误接受（关节帧） | 363 | 319 | 281 |
| 其中左右身份互换 | 358 | 313 | 274 |
| 全视角一致互换造成的误接受 | 340 | 301 | 264 |
| 注入可用性损失 | 11.4% | 13.1% | 14.9% |
| 恢复耗时 p95 | 120 ms | 160 ms | 200 ms |
| 自然事件误接受 / 互换 | 36 / 15 | 12 / 2 | 6 / 0 |
| 干净覆盖率 S1 / S2 | 76.7% / 98.1% | 75.5% / 97.4% | 74.5% / 96.7% |

**结论。** 单视角故障已基本被现有多视角一致性挡住（28 个事件共 22 个误接受）。94% 的注入误接受来自“所有视角一致的左右互换”：三角化几何完全自洽，时间门限在 100 ms 后过期，新轨迹即以互换位置重建。确认机制只能推迟，减少约 22%；它对自然再出现更有效（互换 15→0），但覆盖率损失 1.4–2.3 个百分点，超过预设的 0.5 个百分点门槛，误接受也未减半。因此默认保持 N=1，确认保留为可选参数。下一步应针对互换做双假设恢复：重建时同时保留原始与镜像身份，用骨盆/躯干朝向的连续性和历史体型选择，而不是靠等待。

干净数据在事件窗口内的控制可见跳变（相邻已接受值的位移减参考位移）中位 142 mm、最大约 0.9 m，S1 还有 72 个被接受的左右互换关节帧，说明自然互换已经存在，不只是注入问题。注入只改检测输出，不是物理遮挡；MPI 参考为无标记多视角捕捉；无硬件验证。

**冻结测试集（S3/S5/S7/S8，此前从未使用）。** 每个序列取一个推理前固定的居中 30 s 窗口，共 8 段、6,000 帧、216 个注入事件。S3/S5 原视频为 50 Hz，按步长 2 降到 25 Hz。冻结代码哈希 `f6e73338…`；修改导入代码后重跑开发集，结果与原运行逐值相同。测试集只评测一次：

| 指标 | 默认 N=1 | N=3 | 门槛 |
|---|---|---|---|
| 超过 500 mm 的输出（干净 / 注入） | 157 / 808 | 157 / 808 | 不增加：通过 |
| 干净平均覆盖率 | 94.74% | 92.95% | 损失 ≤0.5 个百分点：未通过 |
| 注入误接受 | 1638 | 1256（−23%） | 减半：未通过 |
| 控制可见跳变超出干净对照的 p95 | 367 mm | 376 mm | 不变差：未通过 |
| 自然事件误接受 / 互换 | 1150 / 577 | 883 / 429 | — |

测试集复现了开发集结论：全视角一致互换占注入误接受的 90%（1478/1638），300/600 ms 事件分别贡献 438/1024。干净数据中被接受的自然左右互换有 665 个关节帧，S5 两段占 451 个；自然事件后约 18% 的关节在 1 s 内未恢复。单视角互换和时间错位在新人物上分别造成 94 和 42 个误接受，比开发集多。默认保持 N=1。见[验收报告](../reports/recovery-events-2026-10-18.json)。

下一步改为身份恢复：轨迹过期或被时间门拒绝后，同时保留原身份和左右镜像两个假设，用躯干/骨盆朝向的连续性、已学体型和各视角的二维证据选择；证据不足时保持 `reacquiring`，不输出新动作。仍需先在开发集上通过同一套门槛，测试集已被本轮使用一次，下一候选应只再评测一次。
