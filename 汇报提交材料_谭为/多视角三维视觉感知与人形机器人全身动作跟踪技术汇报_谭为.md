## 2. 主线算法各阶段数学原理与工程实现

### 2.1 阶段一：多视角无标记二维姿态感知 (`MultiViewPoseDetector`)
系统采用 4 台环绕布置的同步 RGB 相机（`Cam 0` 左前、`Cam 2` 右前、`Cam 5` 右后、`Cam 7` 左后，分辨率 `2048×2048`，帧率 `25 Hz`），全程不依赖任何反光球、ArUco 或 AprilTag 人工标识：
1. **人体检测与主目标关联**：每视角通过 YOLOv8 提取人体候选框，结合多视角极线几何一致性与历史轨迹锚点锁定场景中的唯一受试者。
2. **23 关键点提取**：裁剪受试者区域输入 RTMPose 网络，提取 **COCO-17 全身关键点**（鼻、双目、双耳、双肩、双肘、双腕、双髋、双膝、双踝）以及 **Halpe-26 双足 6 个精细关键点**（左右脚跟 `heel`、大脚趾 `big_toe`、小脚趾 `small_toe`），输出图像坐标 $u_{c,j} = [x_{c,j}, y_{c,j}]^\top$ 与检测置信度 $s_{c,j} \in [0, 1]$。

### 2.2 阶段二：多视角鲁棒三角化与因果三维状态滤波 (`ContinuousHumanState`)
1. **置信度加权 DLT 与 Huber 迭代重加权三角化**：
   已知相机内参矩阵 $K_c \in \mathbb{R}^{3\times 3}$ 与外参 $[R_c \mid t_c] \in \mathrm{SE}(3)$，构成投影矩阵 $P_c = K_c [R_c \mid t_c]$。对于第 $j$ 个关键点，每个可见视角 $c$（满足 $s_{c,j} \ge s_{\min}$）提供两条线性投影约束：
   $$w_{c,j} \begin{bmatrix} x_{c,j} p_{c,3}^\top - p_{c,1}^\top \\ y_{c,j} p_{c,3}^\top - p_{c,2}^\top \end{bmatrix} \tilde{X}_j = 0$$
   通过奇异值分解（SVD）求得初值后，以像素重投影残差 $e_{c,j} = \|\pi(P_c \tilde{X}_j) - u_{c,j}\|_2$ 执行 Huber 权重更新，剔除单视角自遮挡或背景误检引起的异常射线，恢复三维坐标 $X_j(t_k) \in \mathbb{R}^3$。
2. **因果滑动窗口滤波与骨骼长度软约束**：
   为保证严格因果性（不使用任何未来帧 $t > t_k$），对最近 $W$ 帧历史三维观测施加因果 Savitzky-Golay 二阶多项式拟合与双侧肢体对称骨长软投影，直接解析导出平滑的三维关节位置 $p_j(t_k)$ 与线速度 $\dot{p}_j(t_k)$。

### 2.3 阶段三：`BRM-C2` 前端——奇异壁垒连续运动学重定向 (`retarget_continuous_pose`)
从三维人体骨架到宇树 G1 EDU（29 自由度：双腿 12 + 腰部 3 + 双臂 14）的运动学映射包含三个核心步骤：
1. **骨盆局部坐标系与同构比例重定向**：
   - 取人体左右髋中点 $p_{\text{pelvis}} = \frac{1}{2}(p_{\text{l\_hip}} + p_{\text{r\_hip}})$ 与肩中点 $p_{\text{thorax}} = \frac{1}{2}(p_{\text{l\_sh}} + p_{\text{r\_sh}})$，构造骨盆局部正交基 $R_{\text{pelvis}} = [e_x, e_y, e_z]$，从中提取机器人根部横滚/俯仰/偏航角 $(\phi, \theta, \psi)$。
   - 按 G1 下肢总长与人体下肢实测长度的固定比例因子 $\alpha_{\text{leg}} = L_{\text{G1,leg}} / L_{\text{human,leg}}$ 缩放骨盆水平位移 $\Delta xy$ 与骨盆高度 $z_{\text{root}} \in [0.48\text{ m}, 0.95\text{ m}]$，保证机器人的每一步迈步与下蹲均直接来源于源人体的骨盆与双腿运动。
2. **四肢单位方向向量匹配**：
   在骨盆与胸腔局部坐标系下，提取大腿、小腿、上臂、前臂的单位方向向量 $d_{\text{human}} \in \mathbb{S}^2$，通过阻尼最小二乘逆运动学（Damped Least-Squares IK）最小化机器人正向运动学连杆方向 $d_{\text{G1}}(q)$ 与人体方向之间的夹角误差：
   $$E_{\text{dir}}(q) = \sum_{l \in \mathcal{L}} w_l \|d_{\text{G1},l}(q) - d_{\text{human},l}\|_2^2$$
3. **肩肘万向节奇异区软壁垒（Singularity-Barrier Regularization）**：
   当人体大角度摆臂伴随转身（如 `s1_walk` 第 `110~142` 帧）时，球面肩关节靠近欧拉奇异区（$\text{pitch} \to -\pi,\; \text{roll} \to +\pi/2$），传统无壁垒 IK 极易跳入“肩后翻 + 肘反折”的伪局部极小值分支并被帧间限速锁死。`BRM-C2` 在 IK 目标函数中引入平方铰链奇异软壁垒势函数与自适应分支连续性代价：
   $$E_{\text{barrier}}(q) = w_{\text{p}} \max(0,\, -q_{\text{sh,pitch}} - 1.90)^2 + w_{\text{f}} \max(0,\, -q_{\text{sh,pitch}} - 1.55)^2 \max(0,\, |q_{\text{sh,roll}}| - 1.25)^2$$
   $$q_{\text{ik}}(t_k) = \arg\min_{q \in [q_{\min}, q_{\max}]} \Big( E_{\text{dir}}(q) + E_{\text{barrier}}(q) + \lambda_{\text{cont}}(t_k) \|q - q_{\text{ik}}(t_{k-1})\|_W^2 \Big)$$
   实测表明，该软壁垒使 `s1_walk` 上肢方向误差 `>20°` 的奇异翻转帧数从 **38 帧直接降至 6 帧**（P95 方向误差从 `22.5°` 降至 `11.6°`），且正常活动区零干预。

### 2.4 阶段四：`BRM-C2` 后端——单调门控柔化 $C^2$ 轨迹生成 (`build_brm_c2_reference_stream`)
25 Hz（$\Delta T = 40\text{ ms}$）的离散重定向姿态不能直接作为 50 Hz（$\Delta t = 20\text{ ms}$）控制器的阶跃输入，否则会产生巨大的高频加速冲击。同时，传统生成方法面临一个核心矛盾：
- 若强制全身关节等比例同步且每帧末目标速度归零（`GroupSync-ZeroV`），慢速关节会拖慢快速关节，且每个 $40\text{ ms}$ 边界都要减速制动，导致大跨度深蹲（如 `s1_exercise`）蹲不到底；
- 若逐关节赋予全额差分终端速度并向前外推（`Barrier-FullRate`），在动作波峰/波谷换向处会产生严重的速度超调，导致 50 Hz 控制流跃度飙升（P95 达 `2608 rad/s³`）。

**`BRM-C2` 后端通过两项机制彻底解决了这一矛盾**：
1. **单调同向门控阻尼过境速度（Monotonicity-Gated Damped Target Velocity）**：
   由最近三帧已到达的因果重定向姿态计算前后两段有限差分角速度 $\dot{q}_k = (q_k - q_{k-1})/\Delta T$ 与 $\dot{q}_{k-1} = (q_{k-1} - q_{k-2})/\Delta T$。仅当两者严格同号（处于单调连续运动段）时，赋予 `0.45` 倍阻尼过境速度；一旦出现换向极值点（$\dot{q}_k \cdot \dot{q}_{k-1} \le 0$），立即强制目标速度归零：
   $$v_{\text{target},j}(t_k) = \begin{cases} \operatorname{clip}\!\big(0.45\,\dot{q}_{k,j},\; -0.7 v_{\max},\; 0.7 v_{\max}\big), & \text{若 } \dot{q}_{k,j} \cdot \dot{q}_{k-1,j} > 0 \\ 0, & \text{若 } \dot{q}_{k,j} \cdot \dot{q}_{k-1,j} \le 0 \end{cases}$$
2. **双层柔化三阶 Ruckig 解析样条生成**：
   在每个 50 Hz 控制拍（$\Delta t = 0.02\text{ s}$），每个关节独立求解三阶精确受限的 Ruckig 轨迹：
   - **主跟踪层（柔化边界）**：最大角跃度 $|\dddot{q}| \le 1500\text{ rad/s}^3$，最大角加速度 $|\ddot{q}| \le 90\text{ rad/s}^2$，最大角速度 $|\dot{q}| \le 6.0\text{ rad/s}$；
   - **大跨度追赶兜底层**：仅当单步位移跨越超出柔化包络时回退至硬件全额边界（$3000\text{ rad/s}^3 / 120\text{ rad/s}^2$），并同时验证下一拍零速制动可达性，确保任何时刻轨迹 100% 解析可解且严格不越界。

### 2.5 阶段五：全身闭环强化学习物理跟踪执行 (`SONIC` @ 50 Hz / MuJoCo 1000 Hz)
生成的 50 Hz 严格 $C^2$ 连续参考流驱动单一全身强化学习策略 **`SONIC`**（[`SonicAdapter`](file:///c:/Users/TanWei/Desktop/三维位姿估计/scripts/benchmark_controllers.py#L140-L195)）：
- **100% 实时因果输入**：在每一控制拍 $t$，策略仅读取当前因果参考帧 $(q_{\text{ref}}(t), \dot{q}_{\text{ref}}(t), r_{\text{ref}}(t))$（在编码器窗口中将当前参考帧因果复制填充，**零未来帧预瞄**），结合机器人本体 IMU 与关节编码器反馈推理出 29 维动作 $a_t$。
- **1000 Hz 物理闭环**：动作映射为 PD 目标角 $q_{\text{des}} = q_0 + k_a a_t$，在 MuJoCo 物理引擎中以 `1000 Hz`（每控制拍 20 个物理子步）计算关节力矩 $\tau = K_p(q_{\text{des}} - q) - K_d \dot{q}$ 并与地面接触摩擦作用，驱动机器人完成真实动力学步态与平衡。

## 4. 现存技术瓶颈与下一步攻关方案

根据实测数据与物理轨迹分析，当前主线链路仍存在以下 4 个需要正视的技术局限：

### 问题 1：长距离行走与大角度转身下的全局 XY 路径累积漂移
- **实测现象**：尽管 `BRM-C2` 将 `s1_walk` 的全局 XY 路径误差 P95 从无壁垒基线的 `1.102 m` 降低到了 `0.828 m`（5 序列平均 `0.612 m`），但在开环视觉根部参考下，机器人足端与地面接触时的微小切向滑移（Micro-slip）和转身角速度偏差仍会随时间积分产生分米级的全局位置漂移。
- **可能解决方案**：
  1. **引入足端触地相位锚定（Contact-Anchored Odometry）**：利用阶段 1 提取的 Halpe-26 足跟/脚趾三维关键点识别支撑脚静止期，将根部水平位移增量绑定在支撑脚接触锚点上，消除非物理的“滑步”速度指令；
  2. **低频视觉位置外环纠偏**：在 `SONIC` 策略的参考根节点速度输入上叠加基于视觉人体位置与机器人本体里程计差值的弱比例积分（PI，带宽 `< 0.5 Hz`）漂移修正项。

### 问题 2：柔化跃度边界在高频急促往复动作中的瞬态相位滞后
- **实测现象**：`BRM-C2` 将常规跃度上限从 `3000 rad/s³` 柔化至 `1500 rad/s³`、角加速度从 `120 rad/s²` 柔化至 `90 rad/s²` 后，电机冲击减半，但在 `s1_crouch` 这种高频急促连续起蹲片段中，全身关节 RMSE 为 `21.08°`，比保留 `3000 rad/s³` 跃度的 `Barrier-GroupSync`（`19.84°`）高出 `1.24°`。
- **可能解决方案**：
  - **基于运动频率/残差的自适应跃度包络调度（Adaptive Jerk Scheduling）**：当关节位置跟踪残差 $|q_{\text{ik}} - q_{\text{ref}}|$ 小于 `8°` 时保持 `1500 rad/s³` 柔化边界；当检测到连续快速换向且残差超过阈值时，平滑插值放宽跃度边界至 `2200~2600 rad/s³`，兼顾低速柔顺性与高频响应带宽。

### 问题 3：稀疏关键点对前臂自旋与手腕/踝关节完整三维朝向的可观测性受限
- **实测现象**：COCO-17 + 足部 6 点仅能提供上臂与前臂的连杆中心线向量。当肘部完全伸直（奇异共线）或手部被躯干遮挡时，前臂绕自身轴线的旋转（Pronation/Supination）与手腕偏航自由度缺乏几何观测约束，只能退化保持标称姿态。
- **可能解决方案**：
  - **引入全身稠密关键点或参数化网格先验**：将前端 2D 检测器升级为支持手部关键点的 **RTMW-WholeBody (133 点)**，能够直接通过手掌平面法向约束前臂轴向旋转与腕关节角度。

### 问题 4：120 ms 端到端感知-控制延迟导致的动态相位差
- **实测现象**：本报告所有闭环指标均在严格叠加 `120 ms` 端到端因果延迟（模拟多相机抓图 + 2D 检测 + 三角化 + 通信耗时）下测得。在快速挥臂（`s1_walk`、`s2_sports`）期间，纯粹由 `120 ms` 时间平移引起的表观关节误差就占了约 `6°~9°`。
- **可能解决方案**：
  - **TensorRT 4 视角批处理推理 + 因果前瞻状态补偿**：将 4 视角 YOLOv8 + RTMPose 合并为单个 GPU TensorRT FP16 Batch=4 引擎，可将视觉感知耗时压降至 `18~25 ms`；同时在阶段 4 利用 `BRM-C2` 的单调门控速度对已确认的单调运动段进行 `20~30 ms` 的受限因果前瞻补偿。

## 5. 宇树 G1 EDU 实机部署工程考量（Sim-to-Real 路线图）

当前所有闭环验证均在 **MuJoCo 1000 Hz 全动力学仿真环境**下完成。要将本主线链路（`Multi-View RTMPose -> BRM-C2 -> SONIC`）迁移至宇树 G1 EDU 真实物理硬件，需落实以下五项实机工程对接：

1. **多相机硬同步采集与单调时钟对齐**
   - 实机现场的 4 台工业相机必须使用硬件 GPIO 同步触发或 IEEE 1588 PTP 精密时钟同步（帧间曝光偏差 `< 2 ms`），避免多视角异步采集在快速摆臂时造成三角化伪影。
   - 视觉工作站与 G1 机载计算单元（Orin NX）统一使用单调时钟（`CLOCK_MONOTONIC`）打戳，若网络抖动导致视觉帧晚到，由本机 50 Hz `BRM-C2` 后端的已验证制动轨迹（Certified Stopping Plan）无缝接管，绝不下发阶跃指令。
2. **Sim-to-Real 本体动力学与关节执行器标定**
   - 严格核对实机固件的 29 关节零位偏置（Zero Offset）、关节正方向符号、电机减速比与转子反射惯量（`armature`）。
   - 实机底层电机驱动器（`LowCmd`）的刚度 $K_p$ 与阻尼 $K_d$ 必须与 `SONIC` 策略训练及 MuJoCo 仿真中的 `TwistPlant` 配置逐关节对齐；首次上机需在悬吊保护架下以 `0.3× -> 0.6× -> 1.0×` 分级放大刚度验证无高频自激振荡。
3. **50 Hz `BRM-C2` 跃度保护在实机减速器寿命上的价值**
   - 实机谐波/行星减速器对高频力矩冲击极为敏感。`BRM-C2` 将 50 Hz 参考跃度严格限制在 `1500 rad/s³` 以内（比常规方案降低近 50%），并在换向点强制零目标速度，能显著抑制实机 PD 控制器的微分项（$K_d(\dot{q}_{\text{ref}} - \dot{q})$）噪声放大与机身结构共振。
4. **地面接触力学与足底摩擦适配**
   - 实机实验室地面（环氧地坪、橡胶垫或木地板）的静/动摩擦系数与仿真默认橡胶地面存在差异。部署初期应在防滑橡胶地面测试，并监控实机踝关节力矩饱和度与 IMU 角速度残差。
5. **实机分级上机验证流程**
   - **Step A（悬空运动学与延迟环回测试）**：机器人在龙门架悬空状态下运行完整视觉到 `BRM-C2` 50 Hz 链路，验证人机左右肢体 1:1 对应、肩肘奇异区无翻转及端到端延迟 `< 60 ms`；
   - **Step B（双足原地姿态模仿与深蹲测试）**：脚掌全接触地面，测试上肢挥动、转腰与 `BRM-C2` 连续深蹲（验证 `z = 0.50 m` 深蹲平衡）；
   - **Step C（全身步态与转身跟踪测试）**：在安全绳保护下逐步放开小步幅行走与原地转身模仿。
